# Security

This repository is a deliberately vulnerable demonstration agent. Its weaknesses are the point, and
a report that it can be jailbroken is not a finding.

What *is* worth reporting:

- Anything that makes the `hardened` level fail to hold, since that is the true negative the whole
  demonstration depends on.
- Anything here that could harm someone running it — a dependency vulnerability, or a way the agent
  could reach real data.

Open an issue on this repository.
